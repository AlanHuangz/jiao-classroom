和 AI agent 一起做出來的

老師沒有寫程式。老師做的是：說出孩子需要什麼、試用、挑毛病、再說一次。
剩下寫程式、測試、修錯的工作，是 AI agent 做的。

◀ 回體驗館

1聊天 AI 和 AI agent 差在哪？

很多老師用過 ChatGPT、Gemini 這類聊天 AI：問它問題、請它出題、改文章。AI agent 是另一種用法——它不只回答，它會自己動手把事情做完。

聊天 AI

很會回答問題的顧問

  • 你問，它回答一段文字、一張圖、一段程式碼
  • 要自己複製、存檔、打開試試看
  • 壞掉了，要自己把錯誤訊息貼回去問
適合：出題、寫通知單、改作文、找資料
AI agent

坐在你電腦前的助教

  • 你說「我要什麼」，它自己建檔案、寫程式
  • 它會自己打開來測試，發現錯誤自己修
  • 做好了告訴你檔案在哪，直接就能用
適合：互動教具、班級網頁、學習單、整理資料、剪影片

挑出毛病
🔁再說一次
agent 修改、上線

每一個活動都是這樣來回好幾次。例如：

老師：「題目說一排坐 9 個人，你卻排成兩排；披薩應該是一整圈，不是一片一片排成兩排。要跟題意吻合，孩子才看得懂。」
→ agent 把表演廳改成一排 9 個座位排成一直線、披薩改成整個圓切 8 片、小火車加上車頭和車廂，自己逐題操作測試後交回。
老師：「我不想直接告訴孩子『餘數一定要比除數小』，我想要透過操作讓孩子自己發現。」
→ agent 做了「餘數實驗室」：孩子自己把草莓裝盤，裝到不能再裝時，自己看見剩下的一定比一盤少。

教學的判斷，全部是老師做的——要不要給提示、什麼時候加題、哪裡會有迷思。agent 負責把這些想法變成真的能用的東西。

4怎麼開始？（以 Claude 為例）

  1. 到 claude.ai 註冊帳號可以用 Google 帳號登入。
  2. 訂閱付費方案（Pro）agent 功能（Claude Code）包含在付費方案裡，免費方案沒有。Pro 每月 20 美元，年繳約每月 17 美元；價格以官網為準。
  3. 下載 Claude 桌面版並登入Windows、Mac 都有，在官網就能下載。
  4. 打開「Code」分頁，選一個資料夾例如在桌面新增一個「我的教具」資料夾，agent 做的檔案都會放在這裡。
  5. 用中文打字，說你想做什麼它做的時候會告訴你在做什麼；需要用到你的電腦（例如開瀏覽器測試）時會先問你。

其他公司也有類似的 agent 工具，用法大同小異。

5第一次怎麼開口？

我是國小三年級老師。幫我做一個網頁小遊戲，讓孩子練習 2 到 5 的乘法。要用拖拉積木的方式讓孩子自己排出來，不要選擇題。做成一個 HTML 檔，存在這個資料夾，做好告訴我怎麼打開。
孩子說第一關太難了。第一關改成只有 2 和 3 的乘法，按鈕再大一點，答錯的時候不要直接給答案，請他再數一次積木。
  • 說清楚三件事：給誰用（幾年級）、要學什麼、孩子要怎麼操作。
  • 一次改一件事。做好一定自己先試玩，哪裡怪就直接說「這裡怪」。
  • 不懂就問它：「這是什麼意思？」「要怎麼打開？」「怎麼分享給學生？」
  • 先從小東西開始：一張學習單、一個抽籤工具，做成功一次，就知道它能做到什麼。

6要注意的事

  • 學生個資：孩子的真實姓名、照片不要放到公開的網頁上。這個體驗館裡的名字都是虛構的。
  • 版權：課本、習作的掃描頁有版權，自己班上用和放到公開網站是兩回事。
  • AI 也會做錯：一定要自己試過再給孩子用。老師的專業判斷，永遠是最重要的那一環。

7想在自己班上用這套教室？

這套教室是為一個 7 人的班級量身做的（座號、班級代碼、教材進度都是那個班的）。如果你想用在自己班上，有兩條路：

  • 研習或共備時：用這個體驗館示範給其他老師看，不用連線、不用學生。
  • 自己做一套：有了 agent，你可以請它照你的班級人數、你的教材，做出屬於你班上的版本——就像這位老師一樣。
